### User Groups

#### Purpose

This page explains how to create, edit, delete, and manage user groups within an organisation in User Management.

#### User Groups

##### What is a User Group?

A user group is a department or functional unit used to organize users within an organisation.

- An organisation can have multiple user groups.
- A user group belongs to only one organisation.
- User group names must be unique within the same organisation.

#### Create a User Group

1. Log in.
2. Go to **User Management**.
3. Select the target organisation.
    - **Note:** Organisation administrators do not need to select an organisation because they are assigned to only one organisation.
4. Open the **User Groups** section.
5. Click **Create user group**.
6. Enter the user group name.
7. Click **Save**.

The new user group is added to the user groups table.

#### Edit a User Group

1. Log in.
2. Go to **User Management**.
3. Select the target organisation.
    - **Note:** Organisation administrators do not need to select an organisation because they are assigned to only one organisation.
4. Open the **User Groups** section.
5. Find the user group and click **Edit**.
6. Update the name.
7. Click **Save changes**.

#### Delete a User Group

1. Log in.
2. Go to **User Management**.
3. Select the target organisation.
    - **Note:** Organisation administrators do not need to select an organisation because they are assigned to only one organisation.
4. Open the **User Groups** section.
5. Find the user group and click **Delete**.
6. Confirm the deletion.

> **Note:** A user group cannot be deleted while it has users assigned to it. Remove all users from the group before deleting it.

#### Assign Users to a User Group

1. Log in.
2. Go to **User Management**.
3. Select the target organisation.
    - **Note:** Organisation administrators do not need to select an organisation because they are assigned to only one organisation.
4. Go to the **Users** section.
5. Select one or more users.
6. Click the **Actions** button to show the actions menu.
7. Select **Add to department** from the action menu to open the form.
8. Choose one or more user groups from the form.
9. Click **Add**.

#### How User Groups Affect Access

User groups are used only to organize users within an organisation. They do not grant permissions or control what users can do in the application.

A user can belong to multiple user groups at the same time because user groups do not affect application permissions.

##### Permissions

- To create a user group, the user performing the action must have the **Create departments** permission.
- To assign users to user groups, the user performing the action must have the **Assign users to departments** permission.
- To delete a user group, the user performing the action must have the **Delete departments** permission.
